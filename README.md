## 🎯 Ringkasan Proyek

**Portfolio Sayid Rafi A'thaya** adalah website portfolio interaktif berbasis **Astro** dengan konsep visual **8-bit Chromatic Chaos / Playable Digital Archive**.

Bayangkan layar permainan retro. Halaman pertama adalah *title screen*, pengalaman kerja menjadi *peta quest*, kemampuan menjadi *inventory*, sertifikat disimpan di *vault*, dan kontak ada di *terminal komunikasi*.

LINK WEBSITE: https://sayidportfolio.vercel.app

> [!NOTE]
> Website ini dibangun sebagai **static site**. Astro menghasilkan halaman HTML statis, lalu JavaScript/TypeScript menambahkan interaksi. Tidak ada server atau database yang berjalan saat website dibuka, jadi mudah di-*hosting* dan cepat dimuat.

## ✨ Fitur Utama

### 🎮 1. Antarmuka Bergaya Game 8-bit

- Latar pixel art, elemen kota, dan efek visual pada bagian Hero.
- Komponen dekoratif bertema pixel: badge, ikon, sprite, sigil, segel, dan blade.
- Palet enam warna utama: merah, kuning, biru, ungu, hitam, putih.

### 🗺️ 2. Peta Pengalaman (Career Quest Map)

- Setiap pengalaman punya periode, jabatan, organisasi, ringkasan, teknologi, status, dan **posisi pada peta**.
- Dirender oleh `CareerQuestMap.astro`.

### 🧰 3. Skill Matrix

- Kemampuan dikelompokkan menjadi **Build**, **Data**, dan **Voice**.
- Tiap kelompok punya warna, glyph, dan koordinat visual.
- Tidak menampilkan persentase penguasaan, karena datanya memang tidak ada.

### 🌌 4. Project Multiverse

- Tiga proyek utama tampil sebagai dunia berbeda (`ProjectMultiverse.astro`, `ProjectWorld.astro`).
- Setiap proyek punya halaman detail dinamis: `/projects/[slug]/`.

### 🏅 5. Credential Vault

- 23 sertifikat dalam 4 kategori, dengan indeks navigasi, metadata, preview, dan akses ke file asli.
- Thumbnail ringan untuk daftar, file asli (PDF atau gambar) untuk dibuka.

### 📸 6. Field Captures

- 10 dokumentasi kegiatan (acara kampus, panggung, organisasi, dan lainnya) lengkap dengan alt text dan caption.

### ⚙️ 7. Kontrol Pengguna

- Toggle tema terang/gelap dan toggle motion.
- Navigasi responsif, indikator progres scroll, penanda navigasi aktif.

## 🧩 Arsitektur Sistem

Portfolio ini memakai pendekatan **Static Site**. Konten, tampilan, dan interaksi dipisahkan dengan jelas.

```text
   +-----------------------------------------------+
   |  src/data/portfolio.ts   (SUMBER KONTEN)       |
   |  profil · pengalaman · skill · proyek ·        |
   |  sertifikat · arsip · field captures           |
   +----------------------+------------------------+
                          |   divalidasi oleh
                          |   src/types/portfolio.ts
                          v
   +-----------------------------------------------+
   |  src/pages/index.astro                         |
   |  mengatur urutan section & memproses data      |
   +----------------------+------------------------+
                          |
                          v
   +-----------------------------------------------+
   |  Komponen Astro + CSS                          |
   |  CareerQuestMap · SkillMatrix ·                |
   |  ProjectMultiverse · SectionHeading · ...      |
   +----------------------+------------------------+
                          |   dibungkus oleh
                          v
   +-----------------------------------------------+
   |  BaseLayout.astro                              |
   |  header · nav · tema · motion · footer · SEO   |
   +----------------------+------------------------+
                          |   npm run build
                          v
   +-----------------------------------------------+
   |  dist/   (HTML + CSS + JS + gambar + dokumen)  |
   +-----------------------------------------------+
```

### 💡 Apa Arti "Static Site"?

- Halaman dibuat **sekali saat build**, bukan setiap kali dibuka pengunjung.
- Tidak butuh PHP, Node.js server, atau database di production.
- JavaScript hanya **meningkatkan pengalaman** (tema, animasi, preview), bukan syarat agar konten terlihat.
- Website ini **bukan SPA**: tiap halaman tetap berupa HTML nyata.

## 🔄 Alur Kerja Konten

### Contoh: Menambah Sertifikat Baru

```text
   [1] Taruh file sertifikat di public/certificates/
        |
        v
   [2] Taruh thumbnail JPG di public/certificates/thumbs/
        |
        v
   [3] Daftarkan entri baru di array `certificates`
       (src/data/portfolio.ts)
        |
        v
   [4] Pilih kategori: web | data | leadership | award
        |
        v
   [5] npm run verify  (lint + check + build)
        |
        v
   [6] Jumlah sertifikat di heading & indeks
       ikut diperbarui otomatis
```

| # | Tahap | Apa yang Terjadi |
|:-:|---|---|
| 1 | **File** | Dokumen asli (PDF/gambar) disalin ke `public/certificates/` |
| 2 | **Thumbnail** | Preview ringan disimpan di `public/certificates/thumbs/` |
| 3 | **Data** | Entri baru ditambahkan ke `certificates` dengan ID, judul, penerbit, tanggal, kategori, path file, dan `fileType` |
| 4 | **Render** | `index.astro` dan komponen menampilkan entri di vault |
| 5 | **Verifikasi** | `npm run verify` memastikan tidak ada error |

> [!IMPORTANT]
> Menambahkan file ke folder saja **belum tentu** membuatnya tampil. File harus **didaftarkan di data** dan **dirender oleh halaman/komponen**.

### Contoh: Menambah Proyek Baru

1. Tambahkan gambar proyek ke `src/assets/images/`.
2. Tambahkan entri baru di array `projects` (`slug`, judul, deskripsi, teknologi, tahun, peran, URL repo/demo, dan `world`).
3. Astro otomatis menghasilkan halaman `/projects/<slug>/` lewat dynamic route.
4. Jalankan `npm run verify`.

## 🖼️ Manajemen Aset

### Dua Lokasi, Dua Tujuan

| Lokasi | Dipakai untuk | Diproses Astro? |
|---|---|:---:|
| `src/assets/images/` | Gambar sumber (profil, proyek, dokumentasi) | ✅ Ya (dioptimalkan) |
| `public/` | File yang butuh URL tetap (sertifikat, favicon, robots.txt) | ❌ Tidak (disalin apa adanya) |

> [!WARNING]
> Beberapa gambar punya nama yang sama di `src/assets/images/` dan `public/` (misalnya `dirjen_informasi_kominfo_bemkm_unmul.png`, `koor_humas_pdd_pkkmb2026.png`, `magang_telkom.jpeg`). Jangan hapus salah satunya sebelum memeriksa semua referensi.

### Cara Gambar Ditemukan

`src/utils/images.ts` memakai `import.meta.glob` dan menyediakan `findImage()` untuk mencari gambar berdasarkan **nama file tanpa ekstensi**.

```ts
// Di data:
image: "digital-art"
// Dicocokkan dengan: src/assets/images/digital-art.jpg
```

> [!CAUTION]
> Halaman utama **memfilter** gambar yang tidak ditemukan. Jika nama di data salah, item bisa **hilang diam-diam** tanpa membuat build gagal. Selalu cek tampilan setelah menambah atau mengganti nama gambar.

```bash
npm run build
```

Output ada di folder `dist/`:

```text
dist/
├── index.html
├── 404.html
├── archive/index.html
├── projects/
│   ├── heartcalm/index.html
│   ├── purrfect-community/index.html

├── _astro/                # aset hasil pemrosesan Astro
├── favicon.png · favicon.svg
└── robots.txt
```

### 🔁 Urutan yang Benar

1. Perbarui source code atau data.
2. Jalankan `npm run verify`.
3. Periksa hasil di `dist/` (atau `npm run preview`).
4. Publikasikan folder `dist/` ke hosting statis.

> [!WARNING]
> Jangan mengedit `dist/` secara manual. Perubahan akan hilang saat `npm run build` dijalankan lagi.

### ✅ Checklist Sebelum Publikasi

- [ ] `SITE_URL` sudah diisi dengan domain produksi
- [ ] `npm run verify` lulus tanpa error
- [ ] Semua gambar tampil (tidak ada item yang hilang karena salah nama)
- [ ] Semua sertifikat bisa dibuka (PDF dan gambar)
- [ ] Link repo, demo, dan sosial sudah dicek
- [ ] Tema terang/gelap dan toggle motion berfungsi
- [ ] Tampilan mobile sudah diperiksa
- [ ] `robots.txt` dan favicon sesuai

### 📤 Distribusi ZIP

`node_modules/`, `.astro/`, dan `dist/` bisa dibuat ulang lewat `npm install` dan `npm run build`, jadi biasanya tidak wajib ikut dalam source project. Sertakan `dist/` hanya jika tujuannya memberikan hasil build siap pakai.
